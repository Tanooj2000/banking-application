Simple definition and use:
Eureka Server is a lightweight service registry for microservices. Services "register" themselves with Eureka under a logical name. When a client wants to call another service, it asks Eureka for the list of available instances for that logical name instead of using a fixed IP or hostname.

Example (simple):
- Service `orders` registers with Eureka as `orders-service` (host+port).
- Service `payments` needs to call `orders`; it asks Eureka for `orders-service` and gets one or more instance addresses. The client or load balancer picks one and sends the request.

Why this helps:
- Removes hard-coded addresses so services can scale up/down or move.
- Enables client-side or server-side load balancing using the registry's instance list.
